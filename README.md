# Rapidata Python Client

Python client to interface with the Rapidata API.

Docs: https://docs.rapidata.ai/

## Using a coding agent?

Point it at the maintained skill instead of letting it read the installed source:

```bash
python -m rapidata skill            # print the guide
python -m rapidata skill --install  # install it into the current project
```

Details and per-agent install commands: https://docs.rapidata.ai/ai_agents/
